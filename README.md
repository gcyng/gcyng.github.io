# controny.github.io

Personal homepage for Gengcong Yang. Plain HTML/CSS, no build step. Served automatically at
[https://controny.github.io/](https://controny.github.io/) via GitHub Pages.

## Structure

- `index.html` — the page (About, Publications, Education)
- `assets/style.css` — styling
- `assets/CV.pdf` — resume, linked from the page
- `assets/profile.jpg` — add your own headshot here (not included yet); the avatar box hides itself if missing

## Notes

- The previous Jekyll blog that lived in this repo has been replaced. Its history is still reachable via
  `git log` / older commits on this branch.
- The companion repo [gengcong-yang-homepage](https://github.com/controny/gengcong-yang-homepage) has the
  same page mirrored at its own GitHub Pages URL.
