# gcyng.github.io

Personal homepage for Gengcong Yang. Plain HTML/CSS, no build step. Served automatically at
[https://gcyng.github.io/](https://gcyng.github.io/) via GitHub Pages.

## Structure

- `index.html` — the page (About, Publications, Education, Awards)
- `assets/style.css` — styling
- `assets/CV.pdf` — resume, linked from the page
- `assets/profile.jpg` — add your own headshot here (not included yet); the avatar box hides itself if missing

## Notes

- The previous Jekyll blog that lived in this repo has been replaced. Its history is still reachable via
  `git log` on this branch.
- This repo was renamed from `controny.github.io` to `gcyng.github.io` after the GitHub account was renamed
  from `controny` to `gcyng` (the repo name must match the username for the user-site Pages URL to work).
